### §5.15.8 standing-pair "not a saga" reclassification (branch spec/standing-pair-not-a-saga-v2, 522e4a135)

Reviewed 2026-06-24. Reclassifies standing-pair creation from cross-context saga → single-context async (one 2-member MLS group). Findings:

- **HIGH — reaper-vs-convergence contradiction (05-contexts.md §5.15.8 line ~1847 "Convergence window").** Claim: "reaping is suppressed for the whole pending-convergence interval" because `did_lo`'s reaper window = its own InvitationBundle deliverability window (`now > max(emit ts) + welcome_ttl`). FALSE when peer is offline > welcome_ttl (7d default): relay drops I_lo at emit+ttl, reaper fires (both conditions met), `did_lo` reaps canonical group WHILE convergence still pending (did_hi never got Welcome). Invariant "exactly one group survives, did_lo's" transiently inverts: did_lo holds nothing, did_hi holds its own self-created orphan it's send-capable on. SELF-HEALS via next standing_context() auto-revive re-drive, so not catastrophic — but the stated justification is logically wrong (proves "window-open ⟹ suppressed", needs "convergence-pending ⟹ window-open"; offline peer breaks it since convergence time is independent of welcome_ttl). Implementer writing assert("convergence pending ⟹ not reaped") would be wrong.
- **LOW — §3.8.1 did:web canonical form incomplete for determinism.** Enumerates host-lowercase/IDN-punycode/:443-omit/no-trailing-dot/UPPERCASE-hex/`:`→%3A. OMITS RFC 3986 §6.2.2.2 percent-decoding of unreserved chars (`%41` vs `A`). Two honest parties feeding divergent encodings derive divergent derived_context_id → convergence failure (not exploit; did:web is fallback-only). W3C did:web method doesn't fill this gap (defers to domain). Fix: add "percent-encodings of RFC 3986 unreserved characters MUST be decoded".

Decidability of anti-spam gate-decidable carve-out (line 1867): VERIFIED decidable (self-created-group-under-id is pure local state). Self-pair guard, block-list-first ordering, generation-check on destroy: all sound. Provenance corrections across ADR-049/DEFERRED/09/sketch/sdk-common: consistent (3 sagas → 2).
