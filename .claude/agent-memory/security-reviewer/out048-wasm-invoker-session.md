# SCP-OUT-048 (feat/outlet-xctx-048-wasm-session, HEAD 4cdc78a89) — 2026-08-01 — SECURE, 0 CRITICAL/HIGH

Browser-invoker on-device signing + node-delegated streaming saga coordination. Files: crates/scp-client-wasm/src/lib.rs (wasm exports), bindings/typescript-wasm/src/{outlet-stream-session,client,types,index}.ts.

**Confirmed-secure:**
- UCAN NEVER minted in-tab — grep clean (mint/delegate/attenuate absent). `ucanToken` is a caller-supplied string forwarded through OutletStreamOpenRequest→coordinator.open. caveats_binding is a SHA-256 commitment over (ucan_cid,...) not a mint.
- Domain separation SOUND (scp-protocol/src/context/outlets/stream.rs): distinct V1 prefixes SCP-OUTLET-{CREDIT,CANCEL,CHUNK-SIG,CAVEAT-BIND}-V1; update_with_len_prefix (len_be32‖bytes) on all variable fields; verify_strict. No credit/cancel preimage confusion possible.
- Trust boundary FAIL-CLOSED: #ingestFrame MLS-decrypts (authenticated context member) THEN outletStreamVerifyChunkSignature over EXACT decrypted bytes vs caller-pinned operatorPk; `if(!verified) throw` (SCP-OUTLET-6110). Sequence enforced `chunk.sequence !== expectedSequence` → gap throw (6131) — catches both replay(<) and skip(>). Malicious node cannot forge/renumber/replay (sig binds context_id,outlet_id,request_id,sequence,caveats_binding,payload). Node drop = pollNext null → abnormal terminal (availability only).
- Input validation on wasm boundary: request_id==16B, caveats_binding==32B, operator_pk==32B+valid Ed25519 point, signing_key_seed==32B — all fail-closed SCP-VALID-7010. serde_json recursion-bounded.
- Seed handling: signing_key_from_seed zeroizes both transient copies; ed25519-dalek v2 has zeroize feature (SigningKey ZeroizeOnDrop). No seed in returned wire bytes (credit/cancel = request_id/grant/seq/sig only), errors, or logs. Panic hook redacts payload.

**Sanctioned caveat (ADR-057 §Consequences "As-built caveat (Slice 3)", NOT a vuln):** invokerSigningSeed momentarily in wasm linear memory; documented at API surface (lib.rs module doc + client.ts + session opts). #1980 = WebCrypto off-wasm; preimage predicates (compute_credit/cancel_preimage) are the forward seam.

**LOW / observations (not auth/injection/secrets-leak):**
- JS-side `#opts.invokerSigningSeed` (Uint8Array) retained unzeroized for whole session lifetime, no dispose(). Beyond the "momentarily in wasm" framing but consistent w/ tab threat model (attacker reading tab memory already has plaintext+group secrets).
- Shared-client data loss: #ingestFrame calls client.drainEvents(contextId) which drains ALL buffered events; non-chunk / co-tenant MessageReceived events are `continue`-skipped = silently DROPPED. If the same ScpBrowserClient is used for streaming AND regular messaging, regular messages vanish. Availability/API-footgun.
- On-device verify security rests entirely on caller-pinned operatorPk authenticity (session trusts caller to source it from MLS-authenticated outlet registration). Trust assumption, out of slice scope.
- Malformed-but-MLS-authenticated frame that passes loose decodeChunk but fails strict wasm serde throws (aborts session) rather than skip — fail-closed; no more power than node-drop.
