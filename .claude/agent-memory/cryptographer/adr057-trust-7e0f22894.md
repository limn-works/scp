## verify_challenge_verification (challenge.rs:868) gate
Ed25519 over canonical preimage (verifier key resolved from verifier_did via
IdentityDidPublicKeyResolver), THEN subject binding (record.subject_did ==
expected_subject), context binding (record.context_id == Some(target) — None
rejected), expiry (expires_at > now). All decision-consumed fields
(passed/score/expires_at/subject_did/context_id/test_count/pass_count) are in
the signed preimage (canonical_challenge_verification_bytes L503, VarBytes
