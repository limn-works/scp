# ADR-049 §9 RED-CS3 — consequence-engine suspension fail-closed (worktree classs-fix-residual, base 272c4d079)

CRYPTO-SOUND (authorization-monotonicity / downward-auth), no HIGH/MED/LOW. Behavioral §9 hole CLOSED; structural residual (whole &mut ContextRoleState still NAMES ceiling/suspended_capabilities) honestly disclosed, not claimed closed.

## The fix
Consequence engine auto-suspends a member via `ContextRoleState.suspended_capabilities` (the downward-auth BLOCKLIST checked suspension-first by `member_has_capability`, roles.rs:924 — suspended ⟹ false even if role grants). Pre-fix this rode the best-effort/coalesced persist through `ClassCSplit.role_state` whole-&mut; a ≤50ms actor-crash lost the suspension and re-granted a denied capability (suspension is NOT re-derived on respawn). Fix: `enforce_triggered_consequences` (governance_logic.rs) is now `#[must_use] -> bool` (true iff a suspension GREW suspended_capabilities); every cell-holding consequence site persists fail-closed keep-direction when true: finalize_send (messaging_helpers.rs:2171→persist_finalized_send free-path upgraded 2316), handle_deliver_incoming (messaging.rs — sink threaded through deliver_incoming/validate_and_drain_timeouts/buffer_ahead_message/deliver_message_and_drain_buffered/run_buffered_post_delivery, all OR-accumulate), settle_tool_economy (tools_helpers.rs:1296 — caller-owned &mut bool sink, persist on BOTH Ok+Err arms), periodic sweep (governance.rs:828). finalize_governance_action path already fail-closed via token.discharge_with (gov_helpers.rs:4903), flag consumed `let _`.
