Mirrors the PyO3 C7 reference [[project-c7-outlet-stream-ffi-grant-and-test-seams]]. New file `crates/scp-ffi/napi/src/outlet_stream.rs` + `outlet_stream/tests.rs`.

**The ONE difference from PyO3: async, no GIL.** napi-rs bridges `async fn`→JS Promise on the module tokio runtime. `poll_next`/`grant_credit`/`cancel`/`terminate` are native `async fn`s that `.await` the receiver/mailbox directly — NO `crate::runtime()` block_on, NO GIL, NO `allow_threads`. The DashMap-ref-across-await hazard is still guarded (clone `Arc`s out of the shard guard, drop guard, THEN await) — mirrors [[dashmap-ref-across-await]]. Everything else (2 CRITICAL invariants, internal grant signing via custody, reserve→apply→reverse, per-instance registry) is a faithful port.

**Structural facts.** Per-instance registry = new `NapiBridgeInstance.outlet_stream_registry: Arc<DashMap<String, outlet_stream::StreamEntry>>` (added to struct + all 3 ctors: new_napi/with_persistence_napi/with_persistence_napi_arc_and_repo, cleared in `bridge_specific_shutdown`). NOT a static (check-no-bridge-globals/handle-affinity). `#[napi]` methods on `Scp` in scp.rs delegate to `outlet_stream_*_on` helpers. Open takes `handle: &NapiContextHandle` (napi handle convention [[typed-bindings-use-handles]]) + `input_json: String`; poll/grant/cancel/terminate take the stream `handle_id` String (opaque per-instance registry key, no NapiContextHandle → no napi_check_handle needed). Byte args/returns use `napi::bindgen_prelude::Buffer` — had to UN-GATE the `use ...Buffer;` in scp.rs (was `#[cfg(allow_in_memory_custody)]`; my pure-wrapper methods need it unconditionally, incl. the `rust-test-napi-production --features server` lane). Errors→`ScpNapiError`: no-active-stream/serialize/sign→Context(CTX_2001), caller-not-invoker→Permission(PERM_3001), bad-bytes/unknown-slug→Validation(VALID_7001), open-reject carries rejection.error_code() verbatim, grant/cancel apply-reject carry grant_error_to_code/cancel_error_to_code.

**Reused C7 runtime API (do NOT re-add).** `Supervisor::open_outlet_stream` (args: ctx,&registry,&outlet_id_typed,input,&invoker_did,timeout_ms,executor,None,None,None,caveat_binding,params — the 3 Nones = invoked_event_sink/misdeclaration_sink/handler_panic_sink), `outlet_stream_reserve_grant`, `outlet_stream_reverse_grant`, `local_mls_epoch`, StreamSessionHandle::{receiver(),apply_credit_grant(sync),apply_outlet_cancel_signed(async),terminate_with_error(sync),current_next_emission_seq}. `spending_ucan` param is validated-format-only, NOT forwarded (matches PyO3). NapiKeyCustody impls KeyCustody (sign/public_key); `entry.custody`=Arc<NapiKeyCustody>, `entry.identity.active_signing_key`=KeyHandle. Revocation checker holds `Arc<DashMap<String,UcanContextState>>` (=bi.ucan_registry) + ctx; is_revoked → `.get(ctx).is_some_and(|s| s.core.revocation_list.is_revoked(cid))`. UCAN validation = `crate::outlets::validate_ucan_for_outlet` (made `pub(crate)`) + `crate::ucan::build_proof_resolver_from_tokens`.
