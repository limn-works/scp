# SDK Trust Layer-1 UCAN classification — fail-closed proof (2026-07-15, branch fix/sdk-coverage-fail-closed-and-parity @8ddce4ab0)

Reviewed APPROVED. Files: bindings/python/scp_sdk/trust.py, bindings/typescript/src/trust.ts, scp.ts (mapBridgeError), errors.ts.

**Core invariant:** Layer-1 CapabilityValidation starts optimistic (all 6 fields True), narrows on first failing token (fail-fast break). all-six-True ⟺ every token fully validated (validateOneCapUri returns null). Any failure returns a narrowed verdict with ≥1 False. not_revoked=True reachable ONLY via "expiry" category (step 11, after revocation step 10 passed) or full pass — NEITHER reachable by a revoked token.

**Revocation prefix narrowed to ("token revoked:",) only — SOUND.** Verified vs Rust: `#[error("token revoked: {0}")]` (scp-protocol/src/crypto/ucan/mod.rs:168) is the exact leaf step-10 string. Parent-chain revocation is wrapped as DelegationChainBroken (validate.rs:889 "parent token failed: token revoked: ..."; Display "delegation chain broken: {0}") → classifier matches _SIGNATURE_CHAIN_PREFIXES FIRST → "signatures" → not_revoked=False. Excluded "revocation unauthorized:"/"revocation failed:" are revoke-MANAGEMENT-side (never step-10); if surfaced → "unknown" → all-false (MORE fail-closed). No revoked token yields not_revoked=True.

**PERM-3030 ordering CORRECT + NECESSARY.** HandleAffinityError is NOT a UcanError enum variant (grep mod.rs = 0); it maps via From<HandleAffinityError> for ScpPyError → ScpPyError::UcanError{code:PERM_3030} (scp-ffi/src/error.rs:737). So in Python 3030 and 3001 are the SAME exception class (bridge.UcanError); ONLY discriminator is message prefix. Display renders `[{code}] permission error: {message}` (error.rs:157). Python checks startswith("[SCP-PERM-3030]") BEFORE classify → re-raise; else 3030 would classify "unknown"→all-false, masking caller-misuse as a false trust verdict. TS uses stronger closed allowlist: absorb ONLY /^\[SCP-PERM-3001\]/, VALID-* → all-false, else throw. Both anchored ^.

**Prefix-confusion resistant:** attacker controls only the interpolated tail ({0}) after the fixed Rust Display prefix — cannot upgrade a failing category to a more-passing one. _extract_core_error em-dash truncation only trims tail; startswith unaffected → worst case "unknown"/all-false.

**mapBridgeError transparent to trust:** preserves message verbatim; trust re-derives from anchored prefix, so error-class mis-typing can't corrupt a verdict. All UcanError variants → PERM_3001 (exhaustive const-match ucan_errors.rs:ucan_error_code, compiler-enforced, no _=> catch-all). WASM made consistent THIS branch (ucan.rs routes UcanError through ucan_error_code + ScpWasmError::Permission renders `[{code}] permission error:` = same format).
