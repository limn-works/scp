LESSON: For a "replace instance-wide guard with per-set gating" PR, the alignment-critical checks are (1) the reservation KEY must be the spec's canonical saga-evidence form (here raw-digest hex per §5.15.8, NOT the display-prefixed id — a prefix-vs-raw mismatch silently defeats cross-saga-type overlap detection); verify with the cross-TYPE overlap test that feeds one saga-type's reserved key into another's context field. (2) An "honest tripwire" CI gate is a COHERENT enforcement story ONLY if it asserts the named semantic tests exist (P6) — a structural gate that merely checks symbol presence without binding to the behavioral proof is enforcement theater. (3) A disallowed-type `#[allow]` for std::sync::Mutex in async code is acceptable iff you PROVE the guard never crosses an await — confirm the returned RAII struct holds `&Mutex` not the guard, so the guard drops at the reserve fn's return.
