Findings ranked by cross-language impact:
- **MAJOR (Kotlin cold-Flow vs shared-single-drain):** contract is ONE drain shared by aggregate()+iterate, terminal cached, second iterate yields nothing. Kotlin Flow is COLD — each `.collect{}` re-runs from scratch. `asFlow()` MUST be backed by the single shared stream (emit-nothing-if-drained), NOT a cold re-executing flow, or collecting twice re-opens/desyncs from `aggregate()`. Nail in canonical contract before C11b.
- **MAJOR (no single canonical verb across 4):** `aggregate()` is the ONLY spelling that can exist in all 4 (Py method / Swift `.aggregate` / Kotlin `aggregate()`); PRD gives TS only `PromiseLike` (no method). Make explicit `aggregate()` the documented canonical verb in ALL 4; `await handle` = Python+TS sugar only. Python already exposes `aggregate()` (good). Directive for mirror.
- **MAJOR (TS thenable auto-drain footgun):** a value that is BOTH `PromiseLike` AND `AsyncIterable` auto-awaits when returned from an async fn / passed to `Promise.all` — silently collapses handle→Aggregate, losing iteration. Python `__await__` is safe (no auto-await); TS is not. Recommend TS DROP PromiseLike in favor of explicit `.aggregate()` (conflicts with PRD AC "satisfies PromiseLike<Aggregate>" → escalate/amend PRD).
- **MAJOR (eager-vs-lazy error-timing divergence):** Python invoke = sync + lazy-open (all open-time rejections — AttenuationViolation/InsufficientFunds/EstimateExceedsBound/concurrent-stream RateLimited/StreamCapExhausted — surface on first await/iterate/grant/cancel, NOT at invoke). PRD Swift is `try await ctx.outlets.invoke(...)` = eager → same misuse throws at a DIFFERENT call site per language. Pick ONE: recommend lazy everywhere → invoke non-async/non-throwing in all 4 (keep Python as-is; amend PRD Swift).
- **MODERATE (await-then-iterate silently empty):** iterate-then-await returns cached Aggregate (documented ✓). Reverse (await/aggregate first, then `async for`) yields ZERO chunks with no error — under-documented. iterate-halfway-then-await correctly drains the REST + returns executor's End.aggregate (sound). Document all three directions identically ×4.
- **MODERATE (cancel/grant before first poll opens the stream):** `_ensure_open` runs inside cancel()/grant_credit() → `cancel()` on a never-iterated handle OPENS (escrow reserve + admission slot) then cancels, and can surface open-errors from a cancel call. Consider cancel-before-open = local `_closed=True` no-op. Document "first control call opens the stream."
- **MODERATE (single-consumer not enforced/documented):** `__anext__` isn't locked (only `_ensure_open` is); concurrent await+iterate on one handle double-polls (FFI serializes but splits chunks + races `_closed`/`_aggregate`). Document handle as single-consumer.
- **LOW:** caller_did default→ctx.identity_did is GOOD (matches pinned-invoker requirement); vocab-drift persists (unary `identity_did` / xctx `invoker_did` / saga+stream `caller_did`) — standardize on `caller_did`. Credit field name `.value` (Py) vs PRD Swift `.raw` — harmonize. `grant_credit(grant=...)` param-name slightly odd under verb. Module docstring lines 5-11 list invoke_cross_context/session_* that are NO LONGER defined in the file (stale). Credit construction-throw-InvalidGrant is the RIGHT cross-lang contract (not Result); Swift/Kotlin need only zero-rejection (UInt32/UInt type bounds range), Py/TS need full range check — acceptable divergence.

SOUND (don't re-flag): single public verb (no invoke_stream, Outlets has only invoke); lazy-open idempotent under `_open_lock`; iterate surfaces terminal Error as a chunk while await RAISES it (intentional dual, documented); aggregate() idempotent; Credit newtype mirrorable (throwing init all 4); ProtocolError sibling-depth hierarchy correct per round-5.
