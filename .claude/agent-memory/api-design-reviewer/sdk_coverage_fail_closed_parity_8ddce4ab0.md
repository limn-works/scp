Branch `fix/sdk-coverage-fail-closed-and-parity` @8ddce4ab0 — **APPROVED, 0 blockers**. Python+TS parity slice + ADR-053 (Proposed).

**RESOLVES prior tracked findings** (supersedes bits of [[trust_signal_wrappers_4sdk]]): the `evaluate_trust`/`evaluateTrust` name collision is now cleanly disambiguated cross-SDK — the four-layer trust result keeps the plain name (`evaluate_trust` / `evaluateTrust` → `TrustEvaluation` object), the bridge-provenance tier one is barrel-exported prefixed (`bridge_evaluate_trust` / `bridgeEvaluateTrust` → `BridgeTrustLevel` int 0-3). Python `__init__` uses `evaluate_trust as bridge_evaluate_trust`; TS index uses `export { evaluateTrust as bridgeEvaluateTrust } from "./bridge"`. TS `evaluateTrust` no longer has the vestigial silently-ignored `contextId` param — now takes a `Context` handle and records contextId from it. Both SDKs' `TrustEvaluation` = identical 8 fields (subject_did/context_id/capability_validation/behavioral_record|null/attestations/endorsements/challenge_results/consequence_structure|null).

**Q-by-Q (all sound):** (1) TrustEvaluation shape byte-parallel Py↔TS. (2) Python `discover_contexts(query)` async = `asyncio.to_thread(bridge.context_discover, query)` — idiomatic, matches module's to_thread pattern; (scp,query) TS vs (query) Py asymmetry is documented + consistent w/ discovery module's other free fns (PyO3 module-level #[pyfunction] vs NAPI per-instance). (3) TypedDicts correct: TrustLevelDict total=True + `sources: NotRequired[...]`, ResolutionPathDict `source_id: str|None` (matches TS `sourceId: string|null`), DiscoveryResult all-8-required w/ mode/metadata_summary `str|None`. PyO3 discovery.rs ALWAYS emits these exact snake_case dict keys (trust_level={"kind"}, resolution_path 4 keys) so Python's blind `cast(DiscoveryResult, dict(item))` is sound — no validation needed unlike TS parseDiscoveryResult (which validates kind + defaults layer bc NAPI looser). (4) ADR-053 PreRotationCustodyProvider = 4-method callback iface (generate/public_key/import_seed_bytes/consume), canonical names locked in a per-binding table (good anti-drift); trait/callback shape is correct for a foreign-impl provider (config-struct shape N/A); single-use handle invalidated Rust-side after consume = misuse-resistant by construction.
