---
name: Multi-pass agent test generation creates systematic duplication
description: Coder agents generating tests in multiple passes duplicate prior tests with trivially different context IDs instead of extending existing coverage
type: feedback
---

When coder agents generate tests in multiple batched passes (e.g., "batch 2 behavioral wiring tests", "quest gates", "comprehensive tests", "24 remaining tests"), each pass duplicates prior tests with minor variations (different context IDs, slightly different thresholds) rather than checking for existing coverage first.

**Why:** Found in batch-2 governance wiring review (2026-03-25). governance.rs grew by 5440 lines but ~2500 lines were near-exact duplicates. At least 25 test functions had functionally identical twins.

**How to apply:** When reviewing test PRs generated by agents, check for duplicate test patterns first. When dispatching coder agents to write tests, instruct them: "CHECK for existing tests covering the same scenario before adding new ones. If a test for the same code path exists, extend it with additional assertions rather than creating a new function." Count unique code paths tested, not test count.
