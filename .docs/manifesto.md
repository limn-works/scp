# Manifesto

## The sieve is dissolving

Software was written by specialists. Not because the ideas required specialization, but because the medium did. Programming is a formal, invented discipline — Moravec's paradox tells us it was always better suited to machines than to human cognition. The barrier to building software was never the ideas. It was the cost of expressing them: knowledge, time, and money. That cost is collapsing.

## The decompression

Agentic coding is not software engineering. It is the decompression of ideas into executable form. Describe what you want; an agent builds it. Use it, discard it, evolve it. Code is digital clay — malleable, immediate, disposable.

Online life today is defined by those who could pass through the sieve. Tomorrow, it will be defined by personal preference. Not because everyone wants to be a developer, but because everyone wants software that serves them specifically. A Cambrian explosion of personal software is inevitable — not as prediction, but as economics. When the cost of building falls below the cost of not having, demand is unbounded.

## Software becomes ephemeral

Software ceases to be a durable artifact. It becomes a substrate — generated on demand, shaped by intent, replaced without friction. The output serves its purpose. It may be discarded, it may evolve, or it may become something entirely different. It does not matter. Code is the commodity. What is projected onto it — identity, trust, relationships, data — is not.

The substrate is disposable. The projected material is not.

## Connecting is the hard part

Building software is becoming trivial. Connecting it is not.

When every person and every agent generates their own software, every application is an island. Identity belongs to the app that created it. Trust is not portable. Relationships are trapped in clients that will be replaced tomorrow. There is no mechanism for two independently generated applications to share anything without manual integration that costs more than either application is worth.

The connective tissue between applications — identity, trust, encryption, authorization, provenance — cannot be generated on demand. It requires protocol.

## SCP

Open. No operator dependency. Transport independent. Designed for a world where agents are the primary actors and humans are the root of trust.

The protocol that agents reach for first when building connected software will, over time, become the substrate for most connected software. That protocol must be open, interoperable, and independent of any single operator.
