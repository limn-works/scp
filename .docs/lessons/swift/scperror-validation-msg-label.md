# `ScpError.Validation` Takes `msg:`, Not `message:`

`ScpError.Validation` is generated by UniFFI from a Rust variant whose field is named `msg`,
and Swift exposes the Rust field name as the argument label. Every other SDK spells the field
`message`, so an author writes `message:` by reflex. The mistake compiles locally when the
XCFramework is not built, because `swift build` skips the target that "does not contain a
binary artifact", and then fails the macOS `Swift / build + test` CI job:

```
error: incorrect argument label in call (have 'message:code:', expected 'msg:code:')
```

Write `throw ScpError.Validation(msg: "…", code: "SCP-XXX-NNNN")`. For any UniFFI-generated
case whose Rust field name differs from the Swift idiom, read the literal labels in
`bindings/swift/Sources/SCP/Internal/ScpBindings.swift`.
