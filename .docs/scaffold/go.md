## C ABI Bridge (cbindgen + cgo)

### Bridge architecture

Rust → cbindgen → C header → cgo → Go

1. `crates/scp-ffi/cbindgen/` exports functions with `#[no_mangle] extern "C"` ABI
2. `cbindgen` generates `scp_ffi.h` C header
3. Go's `cgo` imports the C header and links the shared library
4. Go wrapper functions translate between Go types and C types

### Rust FFI layer

```rust
// crates/scp-ffi/cbindgen/src/lib.rs

/// Create a new SCP identity.
/// Returns an opaque handle. Caller must free with scp_identity_free().
#[no_mangle]
pub extern "C" fn scp_identity_create(
    custody: *const c_char,
    out_handle: *mut *mut ScpIdentity,
    out_error: *mut *mut ScpError,
) -> i32 {
    // Returns 0 on success, -1 on error
}

/// Free an identity handle.
#[no_mangle]
pub extern "C" fn scp_identity_free(handle: *mut ScpIdentity) { }

/// Get the DID string from an identity.
/// Caller must free the returned string with scp_string_free().
#[no_mangle]
pub extern "C" fn scp_identity_did(
    handle: *const ScpIdentity,
    out_did: *mut *mut c_char,
) -> i32 { }

/// Free a string allocated by the FFI layer.
#[no_mangle]
pub extern "C" fn scp_string_free(s: *mut c_char) { }

/// C-visible error type returned by FFI functions.
/// Caller must free with scp_error_free().
#[repr(C)]
pub struct ScpError {
    pub code: *mut c_char,    // e.g., "SCP-CTX-2001"
    pub message: *mut c_char,
}

/// Free an error allocated by the FFI layer.
#[no_mangle]
pub extern "C" fn scp_error_free(err: *mut ScpError) { }

/// Initialize the tokio runtime. Must be called once before any async FFI function.
/// Returns 0 on success.
#[no_mangle]
pub extern "C" fn scp_runtime_init() -> i32 { }

/// Shut down the tokio runtime. Call during application teardown.
#[no_mangle]
pub extern "C" fn scp_runtime_shutdown() { }
```

### cbindgen configuration

`crates/scp-ffi/cbindgen/cbindgen.toml`:

```toml
language = "C"
header = "/* Auto-generated by cbindgen. Do not edit. */"
include_guard = "SCP_FFI_H"
autogen_warning = "/* Warning: this file is auto-generated by cbindgen. Do not modify. */"

[export]

[fn]

[enum]
prefix_with_name = true
```

### Go cgo bindings

```go
// internal/ffi/bridge.go
package ffi

/*
#cgo pkg-config: scp_ffi
#include "bridge.h"
*/
import "C"
import (
    "fmt"
    "runtime"
    "unsafe"
)

type IdentityHandle struct {
    ptr *C.ScpIdentity
}

// Init initializes the Rust async runtime. Must be called once at application start.
func Init() error {
    rc := C.scp_runtime_init()
    if rc != 0 {
        return fmt.Errorf("scp: failed to initialize runtime")
    }
    return nil
}

// Shutdown tears down the Rust async runtime. Call during application cleanup.
func Shutdown() {
    C.scp_runtime_shutdown()
}

func IdentityCreate(custody string) (*IdentityHandle, error) {
    cCustody := C.CString(custody)
    defer C.free(unsafe.Pointer(cCustody))

    var handle *C.ScpIdentity
    var errPtr *C.ScpError

    rc := C.scp_identity_create(cCustody, &handle, &errPtr)
    if rc != 0 {
        return nil, extractError(errPtr)
    }

    h := &IdentityHandle{ptr: handle}
    // Safety net only — callers must use Close()/defer for deterministic cleanup.
    // Finalizers run at GC's discretion, not on scope exit.
    runtime.SetFinalizer(h, func(h *IdentityHandle) {
        C.scp_identity_free(h.ptr)
    })
    return h, nil
}
```

## Error Types

Go errors implement the `error` interface with type assertions for specific error types:

```go
type ScpError struct {
    Code    string // e.g., "SCP-CTX-2001"
    Message string
}

func (e *ScpError) Error() string {
    return fmt.Sprintf("%s: %s", e.Code, e.Message)
}

type IdentityError struct{ ScpError }
type ContextError struct{ ScpError }
type PermissionError struct{ ScpError }
type CryptoError struct{ ScpError }
type TransportError struct{ ScpError }
type ToolError struct{ ScpError }
type ValidationError struct{ ScpError }

// Usage: type assertion
var target *PermissionError
if errors.As(err, &target) {
    log.Printf("Permission denied: %s", target.Code)
}
```

## Module Publishing

Published as `github.com/limn/scp-go` Go module.

```go
// Consumer usage
import "github.com/limn/scp-go"
```

Pre-built shared libraries for each platform are bundled. The cgo build links against these at compile time. Users need a C compiler (gcc/clang) but not a Rust toolchain.
